## Reproduction

```bash
MPLCONFIGDIR=/tmp/krea2-mpl uv run python scripts/generate_blog_assets.py
```

Figures use the purple-obsidian theme and are exported as high-resolution PNG plus SVG. Exact benchmark precision is preserved in the Markdown tables and generator source; chart labels are presentation rounding only.

The dataset montages are intentionally separate from that chart theme: their source RGB and pose-condition pixels are preserved in full, with only subtle obsidian gutters. They use an aspect-ratio-preserving justified editorial layout, and the manifest records every paired cell position and source geometry. Recreate them with `uv run python scripts/generate_dataset_montage.py` from a host that has the read-only PoseBridge snapshot mounted at `/lambda/nfs/adhit/krea2-pose/posebridge_hf`.

## Qualitative appendix execution

The prepared appendix is pinned to Krea-2 Turbo, the materialized `mix-025`
release artifact, 8 steps, CFG 0, `mu=1.15`, control scale 1.0, no Style-LoRA,
and native/aspect-derived geometry. On the CUDA-visible GH200 shell, finish it
with:

```bash
cd /home/ubuntu/krea2-pose-controlnet
uv run python scripts/prepare_qualitative_appendix.py --generate-appendix
```

The command validates the release SHA, controls, output uniqueness, prompt
geometry neutrality, and PNGs; it then updates the manifest, contact sheet, and
`SHA256SUMS.txt`. It stops on a generation error rather than silently retrying.
